# METR4202 — Autonomous Exploration and Target Search

This project implements an autonomous exploration and target-search system using a TurtleBot3 Waffle Pi.

The system uses an occupancy map generated by SLAM to identify unexplored frontiers, constructs a graph to plan exploration routes, and uses Nav2 to navigate between waypoints. The Exploration Manager coordinates navigation, graph updates and recovery.

## 1. Prerequisites

The project was developed using **ROS 2 Humble on Ubuntu 22.04**.

### Additional dependencies

The project uses NetworkX, NumPy, SciPy, OpenCV, `cv_bridge` and Nav2 Simple Commander.

Install these dependencies if they are not already available:

```bash
sudo apt update
sudo apt install -y \
  python3-networkx \
  python3-numpy \
  python3-scipy \
  python3-opencv \
  ros-humble-cv-bridge \
  ros-humble-nav2-simple-commander
```

## 2. Download and build

Clone this repository into a ROS 2 workspace:

```bash
mkdir -p ~/metr4202_demo_ws/src
cd ~/metr4202_demo_ws/src

git clone https://github.com/Reuben678/metr4202_2026_team30.git
```

Build the project:

```bash
cd ~/metr4202_demo_ws

source /opt/ros/humble/setup.bash

colcon build --symlink-install

source install/setup.bash
```

**Note:** If the TurtleBot3 packages are installed in a separate workspace, source that workspace before building the project.

## 3. Run the demonstration

### Launching project nodes

Open a new terminal and run:

```bash
source /opt/ros/humble/setup.bash
source ~/metr4202_demo_ws/install/setup.bash

ros2 launch project_explore demo.launch.py
```

This launches the team's project nodes and connects them to the existing ROS 2 simulation and navigation environment.

**Important:** `demo.launch.py` does not launch Gazebo, SLAM, Nav2 or RViz2. These systems must already be running.

## 4. Optional — Launch our custom RViz configuration

The project includes a custom RViz configuration for visualising the exploration process, including the occupancy map, robot, sensor information and navigation paths.

To launch our custom RViz configuration, open a **separate terminal** and run:

```bash
source /opt/ros/humble/setup.bash
source ~/metr4202_demo_ws/install/setup.bash

rviz2 -d "$(ros2 pkg prefix project_explore)/share/project_explore/config/metr4202_rviz_conf.rviz" \
  --ros-args -p use_sim_time:=true
```

This loads the RViz configuration installed with the `project_explore` ROS 2 package.

**Note:** This step is optional. The demonstration can run using the tutors' existing RViz setup.

## 5. Expected operation

Once the project nodes have initialised, the robot should begin autonomously exploring the environment.

The system will:

1. Retrieve the occupancy map generated by SLAM.
2. Detect candidate exploration frontiers.
3. Update its graph and select navigation goals.
4. Navigate toward selected waypoints using Nav2.
5. Update exploration records and replan as the map changes.
6. Attempt recovery when navigation fails or times out.
7. Evaluate completion when no valid exploration goals remain.

Progress can be observed through the terminal logs and RViz2.

## 6. Stop the demonstration

To stop the project nodes, press **Ctrl + C** in the terminal running `demo.launch.py`.
